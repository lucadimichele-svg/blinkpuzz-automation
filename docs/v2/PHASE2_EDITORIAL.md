# Editorial selection for the creative rebuild

The reviewed opening frames, covers and proof stills show a recurring header, rectangular diagram and instruction plaque. The maze already has real isometric walls. Its isolated inset still leaves much of the phone to signage. The pipe joints read as thin white strokes. The lock requires three comparisons before the object strips mean anything. These observations concern the delivered pictures.

The following editorial estimates use a three-point scale. Higher is better. The axes are predicted two-second entry, spatial legibility, credible decoys and opportunity for a visual payoff. Certainty is independently verified for all ten. All necessary clues are simultaneous in the earlier solve plates. The reproducible selector also reports actual question plus rule word counts. Human comprehension and delight remain unrated.

| Legacy game | Entry / space / decoys / payoff | Decision | Reason |
| --- | --- | --- | --- |
| Laser | 3 / 3 / 2 / 3 | mainstream ready | The emitter and mirrors imply tracing. Build physical optics and light the actual receiver. |
| Maze | 3 / 2 / 3 / 3 | mainstream ready | A route to a flag reads immediately. Enlarge the open passages and keep walls low. |
| Pipes | 3 / 2 / 3 / 3 | requires redesign | Broken conduits and spares deserve the space of a real pump mechanism. |
| Gears | 2 / 2 / 3 / 3 | requires redesign | Fix a driver and ask for one output direction. Motion can show the parity chain. |
| Circuit | 1 / 2 / 2 / 2 | niche/parked | Inverters and XOR require decoding a specialist vocabulary. |
| Nonogram | 1 / 1 / 3 / 2 | niche/parked | Row and column runs compete for small-screen space. |
| Lock | 1 / 2 / 3 / 1 | niche/parked | Three verbal notes precede the interesting ordering decision. |
| Balance | 2 / 2 / 2 / 2 | niche/parked | Simultaneous equations reward deliberate tabletop play. |
| Routes | 2 / 2 / 2 / 2 | niche/parked | Fare arithmetic interrupts the travel metaphor. |
| Pattern | 3 / 3 / 2 / 2 | niche/parked | The rotation is legible, but the current bitmap choices have limited physical payoff. |

Phase 2 keeps the V2 catalog intact. A separate experience contract drives eight gameplay sets. A seed produces physical facts, an independent oracle, geometry keyed to those facts, a fixed camera and a reveal track. The final composite uses locally rendered 3D sets, native-resolution type and motion derived from the proof. The development workflow renders its own 9:16 portrait masters and packages them after QA.
